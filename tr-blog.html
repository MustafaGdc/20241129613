Teknoloji Blogum

Teknoloji bloguma hoş geldiniz! Burada web geliştirme, programlama ve modern teknolojiler hakkında öğrendiklerimi paylaşıyorum.

HTML5’e Başlangıç

12 Temmuz 2026

HTML5, modern web sayfalarının yapısını oluşturmak için kullanılan standart işaretleme dilidir. Başlıklar, paragraflar, görseller, bağlantılar ve tablolarla içerik düzenlemeyi sağlar.

Bilgisayar Programcılığı öğrencisi olarak HTML5 ile web sitesi geliştirmeyi öğreniyorum. HTML’i anlamak, web geliştirmede önemli bir ilk adımdır.

Bu ekran görüntüsü, Visual Studio Code ile yazılmış bir HTML5 kodu örneğini gösteriyor.

CSS3 ve Duyarlı Tasarım Öğrenimi

10 Temmuz 2026

CSS3, modern web sitelerinin görünümünü tasarlamak için kullanılan bir stil dilidir. Renkleri, yazı tiplerini, düzenleri, arka planları ve animasyonları kontrol etmeyi sağlar.

Duyarlı web tasarımı, modern web geliştirmenin önemli bir parçasıdır. CSS3 ve Bootstrap sayesinde siteler bilgisayar, tablet ve telefon ekranlarına uyum sağlayabilir.

Bu ekran görüntüsü, CSS3’ün bir web sitesinin görünümünü ve düzenini nasıl geliştirebildiğini gösteriyor.

JavaScript’e Giriş

16 Kasım 2026

JavaScript, web sitelerini etkileşimli ve dinamik hâle getiren bir programlama dilidir. Animasyonlar, etkileşimli butonlar ve form doğrulama gibi işlerde kullanılır.

Bilgisayar Programcılığı öğrencisi olarak web geliştirme becerilerimi artırmak için JavaScript’in temellerini öğreniyorum. JavaScript, modern siteler oluşturmak için HTML5 ve CSS3 ile birlikte çalışır.

Bu ekran görüntüsü, Visual Studio Code ile yazılmış temel bir JavaScript örneğini gösteriyor.
